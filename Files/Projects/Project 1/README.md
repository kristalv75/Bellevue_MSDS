# Exploratory Analysis of Crimes in Seattle

Exploring trends in crime data in Seattle using R.


## Description

Using crime data provided by Seattle Police Department, various trends are explored including amount of crime over 15+ year time period, use of force for past ten years, officer involved shootings for over 15+ years.
